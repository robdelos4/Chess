# Chess
Chess in python using pygame
I wanted to create a chess game where I can control both sides of the board to analyze games I play in real life
and to practice openings.  Here I created a chess game in python.  Add PNG files to images folder /images to with main.py in chess folder.  For example
c:/>chess/main.py
c:/>chess/images
/images/black_bishop.PNG.....ETC.
